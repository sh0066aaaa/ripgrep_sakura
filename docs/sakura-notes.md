# サクラエディタ側の調査メモ

`sakura.chm` / `macro.chm`（2.4.3.7173 同梱）を展開して確認した内容。
実装の根拠になっている部分をまとめてある。

## タグジャンプが認識する形式

ヘルプ「タグジャンプ」より。カーソル行が次の形式なら該当ファイルを開ける。

```
ファイル名
ファイル名 行番号
ファイル名 (行番号)
ファイル名(行番号):
ファイル名 行番号 桁位置
ファイル名 (行番号,桁位置)
ファイル名(行番号,桁位置):
```

- 行番号は改行単位で先頭を 1 とする
- **桁位置は改行単位の行の先頭からの文字数（サロゲートは 1 文字で 2 換算）で先頭を 1**
- Grep の検索結果からも直接タグジャンプできる
- 通常のタグジャンプができなかった場合はダイレクトタグジャンプを試みる

本ツールは `ファイル名(行番号,桁位置): 内容` を採用している。

既定のキー割り当ては `F12`（タグジャンプ）/ `Shift+F12`（タグジャンプバック）。

## コマンドラインオプション

ヘルプ「コマンドラインオプション」より抜粋。

| オプション | 意味 |
|---|---|
| `-X=` | ファイルを開いたときのカーソルの桁位置 |
| `-Y=` | ファイルを開いたときのカーソルの行位置 |
| `-VX=` / `-VY=` | スクロール位置（ウィンドウ左端の桁 / 上端の行） |
| `-CODE=` | 文字コード種別（0=SJIS, 4=UTF-8, 99=自動判別） |
| `-TYPE=` | タイプ別設定を拡張子で強制指定 |
| `-R` | ビューモードで開く |
| `-GROUP=` | タブモードのグループを指定して開く |
| `--` | オプション指定の終端 |

- オプションは大文字小文字を区別しない
- `=` の代わりに `:` も使える
- ハイフンで始まるファイル名は `--` の後に置く

Grep 関連には `-GREPMODE` `-GKEY=` `-GFILE=` `-GFOLDER=` `-GOPT=` などがあるが、
本ツールはサクラエディタ内蔵の Grep を使わないので利用していない。

## 外部コマンド実行 / ExecCommand

ヘルプ「外部コマンド実行」より。

```
ExecCommand( str1 :String, int2 :Integer, str3 :String );
  str1 実行するコマンド文字列
  int2 実行制御オプション
  str3 カレントディレクトリ（省略可、PPA マクロでは省略不可）
```

実行制御オプションは次の値の和。

| 値 | 意味 |
|---|---|
| `0x001` | 標準出力を得る |
| `0x002` | 標準出力を編集中のウィンドウにリダイレクト（指定なしならアウトプットウィンドウ） |
| `0x004` | 編集中の内容を子プロセスの標準入力へ |
| `0x008` | 標準出力を Unicode で行う |
| `0x010` | 標準入力を Unicode で行う |
| `0x020` | ヘッダー・フッター情報を出力する |
| `0x040` | ヘッダー・フッター情報を出力しない |
| `0x080` | 標準出力を UTF-8 で行う |
| `0x100` | 標準入力を UTF-8 で行う |
| `0x200` | カレントディレクトリを有効にする |

注意点:

- **GUI アプリケーションは「標準出力を得る」を使ってはいけない**（画面に表示されない）
- アウトプットウィンドウへ出力中に、他のウィンドウから同時に出力したりタグジャンプすると
  出力が化けることがある

## マクロの種類

ヘルプ「マクロについて」より。マクロは**拡張子で種類を判別**する。

| 拡張子 | 種類 |
|---|---|
| `mac` | キーマクロ |
| `ppa` | PPA マクロ |
| `js` | WSH: JScript マクロ |
| `vbs` | WSH: VBScript マクロ |
| その他 | WSH が認識できるものであれば使える |

- マクロファイルは通常 SJIS として読み込む。UTF-8 BOM 付きなら UTF-8 として読む
- WSH マクロでは関数名に `S_` を付けない（`Editor.InsText "..."`）。`Editor` は省略可能

「その他」に Python を含めるには ActiveScript エンジンの登録が必要。
このマシンでは `VBScript` / `JScript` しか登録されておらず、
さらにサクラエディタが 32bit なので 32bit Python + pywin32 が要る。
したがって**マクロ本体は VBScript にし、処理は外部プロセスに任せている**。

## ExpandParameter の特殊文字

ヘルプ「特殊文字の展開」より、本ツールで使うもの。

| 記号 | 意味 |
|---|---|
| `$F` | 開いているファイルの名前（フルパス） |
| `$C` | 選択中のテキストまたはカーソル位置の単語 |
| `$x` / `$y` | 現在の物理桁位置（バイト数）/ 物理行位置 |

`$C` は「検索ダイアログの条件欄に取り込まれる文字列」と同じ仕様。
複数行を選択していても取得できるのは一番上の 1 行だけで、改行は含まない。
取得できるのは 259 バイトまで。

新規ファイル・Grep 結果ウィンドウ・アウトプットウィンドウでは `$F` は `(無題)` になる。

## マウス操作への機能割り当て

キー割り当て一覧より、次のマウス操作が「キー」として割り当て可能。

| 操作 | 既定の機能 |
|---|---|
| ダブルクリック | 現在位置の単語選択 |
| トリプルクリック | 1行選択 |
| クアドラプルクリック | すべて選択 |
| 右クリック | 右クリックメニュー |
| 中クリック / 左右サイドクリック / ホイール | （環境による） |

`Shift+` `Ctrl+` との組み合わせも別々に割り当てられる。
ヘルプ「共通設定『カスタムメニュー』」にも
「マウスの右クリックに別の機能を割り当てるには、共通設定『キー割り当て』プロパティで行って下さい」とある。

設定は `%APPDATA%\sakura\sakura.ini` の `[KeyBind]` セクションに保存される。

```
KeyBind[000]=0100,30400,30400,30400,30400,30400,30400,30400,30400,ダブルクリック
KeyBind[022]=007b,30940,30941,30814,0,30850,0,30111,0,F12
```

キーコードに続く 8 個の数字が、修飾キーの組み合わせ
（なし / Shift / Ctrl / Shift+Ctrl / Alt / Alt+Shift / Alt+Ctrl / Alt+Shift+Ctrl）
に対応する機能 ID。F12 の行から タグジャンプ = `30940`、
タグジャンプバック = `30941` と分かる。`30400` は現在位置の単語選択。

サクラエディタは終了時に ini を書き出すので、直接編集するときは完全に終了してから行う。

## 単語単位検索の実装差

サクラエディタの「単語単位」は文字種（英数字 / ひらがな / カタカナ / 漢字）の
変わり目を区切りとみなす。ripgrep の `-w` は Unicode の単語境界なので、
漢字・かなも単語構成文字として扱われ、`test` は `test用` にマッチしない。

詳細と対策は [spec.md](spec.md) §8 を参照。
