# rgs 仕様

ripgrep の検索結果をサクラエディタで開くツールの仕様。
実装言語に依存しない形で書いてある（PowerShell 版 / Python 版はどちらもこの仕様に従う）。

## 1. 目的

ripgrep で検索し、その結果を **サクラエディタの Grep 結果形式** に変換して
サクラエディタ上で開く。結果行にカーソルを置いて `F12`（タグジャンプ）を押すと
該当のファイル・行・桁へ飛べる状態にする。

## 2. 全体の流れ

```
引数解析 → (ダイアログ) → rg 実行 → 出力を整形 → 出力先へ渡す
                                                  ├ 一時ファイル + サクラエディタ起動 (既定)
                                                  ├ 標準出力 (-Stdout)
                                                  └ 先頭ヒットを直接開く (-Direct)
```

## 3. コマンドライン

```
rgs [制御スイッチ...] [rg の引数...]
```

制御スイッチは**必ず先頭**に置く。それ以外の引数はすべて rg にそのまま渡す。

| スイッチ | 動作 |
|---|---|
| （なし） | 結果を一時ファイルに書き、サクラエディタで開く |
| `-Dialog` | 検索ダイアログを表示し、その内容で検索する |
| `-Direct` | 先頭ヒットのファイルを、その行・桁で直接開く |
| `-Stdout` | 結果を UTF-8 で標準出力へ書く（サクラエディタのアウトプットウィンドウ用） |
| `-DryRun` | rg を実行せず、渡す引数とカレントディレクトリを表示して終了 |
| `-WordJp` | サクラエディタ互換の単語単位検索に変換する（§8） |
| `-Pos <値>` | ダイアログを出すモニター `active` / `cursor` / `primary` |
| `-Word <値>` | ダイアログの検索文字列の初期値 |
| `-Folder <値>` | ダイアログのフォルダの初期値 |

rg には常に `--vimgrep --no-heading --color never` を付ける。

引数が無く `-Dialog` も無い場合は usage を表示して終了コード 2。

## 4. 出力形式

サクラエディタのヘルプ「タグジャンプ」記載の形式に合わせる。

```
□検索条件  <ユーザーが指定した引数>
□フォルダ  <検索したフォルダの絶対パス>
□既定設定  <使用した rgrc のパス>      ← rgrc を使ったときだけ
C:\path\to\file.c(12,5): マッチした行の内容
C:\path\to\file.c(30,1): マッチした行の内容

該当 2 件
```

- ファイルパスは**絶対パス**。区切りは `\`
- 行番号・桁位置は 1 始まり
- ヘッダー行が `□` で始まるのはサクラエディタの Grep 結果に合わせたもの
  （アウトライン解析でも認識される）
- 該当が 0 件のときは `該当なし` の 1 行のみを出力し、終了コード 1
- rg の走査順は並列処理のため一定しないので、**パス・行・桁で並べ直してから出力する**
  （PowerShell 版は並べ直さず rg の出力順のまま）

## 5. 桁位置の変換

**rg の `--vimgrep` が返す桁はバイト単位、サクラエディタのタグジャンプは文字単位。**
そのまま渡すと日本語を含む行で桁がずれる。

変換規則:

1. マッチ行のテキストを UTF-8 バイト列にする
2. 先頭から `(rg の桁 - 1)` バイトを取り出す
3. それを UTF-8 として復号し、**UTF-16 コード単位の長さ** を数える
4. その値 + 1 が サクラエディタ の桁

サクラエディタのヘルプに「桁位置は改行単位の行の先頭からの文字数
(サロゲートは1文字で2換算)で先頭を1とします」とあるため、
Python では `len(prefix.encode('utf-16-le')) // 2` で数える。

## 6. 文字コード

| 対象 | 規則 |
|---|---|
| rg の出力 | UTF-8。バイト列のまま受け取り、自前で復号する |
| 結果の一時ファイル | **BOM 付き UTF-8**。サクラエディタの自動判定を確実にするため |
| `-Stdout` の出力 | BOM 無し UTF-8 のバイト列を直接書く（コンソールの既定エンコーディングを経由しない） |
| `.cmd` ファイル | **ASCII のみ**。cmd.exe は cp932 で読むため、日本語コメントを入れると壊れる |
| `.vbs` ファイル | Shift_JIS (cp932) |

## 7. rg の呼び出し

### 7.1 検索パスの補完

rg は**パス未指定かつ標準入力がパイプ**のとき標準入力を検索するため、
サクラエディタの `ExecCommand` から呼ぶと入力待ちで固まる。

引数を走査して位置引数（オプションでもその値でもないもの）を数え、
**1 個以下（＝パターンのみ）なら `./` を末尾に足す**。
値を取るオプション（`-e -g -t -T -m -A -B -C -M -j -f -r -E --glob --iglob --type
--type-not --regexp --replace --file --max-count --max-depth --max-columns
--encoding --pre --sort --sortr --threads --ignore-file --context
--before-context --after-context`）の次の引数は値として読み飛ばす。

**この比較は大文字小文字を区別すること。** 区別しないと `-F`（固定文字列）が
`-f`（`--file`）と誤判定され、検索語が読み飛ばされる。

### 7.2 既定オプション

環境変数 `RIPGREP_CONFIG_PATH` が未設定なら、スクリプトと同じ場所か
リポジトリ直下の `rgrc` を設定する。rg 自身がこのファイルを読む。
コマンドラインで指定した引数のほうが優先される（rg の仕様）。

## 8. 単語単位検索（サクラエディタ互換）

rg の `-w` は Unicode の単語境界を使うため、漢字・かなも単語構成文字になる。
そのため `test` は `test用` にマッチしない。
サクラエディタは**文字種の変わり目**を単語の区切りとみなすのでマッチする。

`-WordJp` とダイアログの「単語単位で探す」は後者に合わせる。

検索語の**先頭と末尾の文字種**を判定し、同じ文字種の文字が隣接することを
禁止する先読み・後読みを組み立てて PCRE2（`-P`）で検索する。

| 文字種 | 文字クラス |
|---|---|
| 英数字・アンダースコア | `0-9A-Za-z_` |
| ひらがな | `\x{3041}-\x{309F}` |
| カタカナ | `\x{30A0}-\x{30FF}\x{FF66}-\x{FF9F}` |
| 漢字 | `\x{3400}-\x{4DBF}\x{4E00}-\x{9FFF}\x{3005}` |

```
test  ->  (?<![0-9A-Za-z_])test(?![0-9A-Za-z_])
用    ->  (?<![\x{3400}-\x{4DBF}\x{4E00}-\x{9FFF}\x{3005}])用(?![...同じ...])
```

検索語は正規表現エスケープしてから挟む。`-F` と `-w` は取り除き、`-P` を足す。

以下の場合は rg 標準の `-w` にフォールバックする。

- 正規表現モードと併用したとき（境界の判定ができないため）
- rg が PCRE2 無しでビルドされているとき（`rg --pcre2-version` の終了コードで判定）

## 9. 検索ダイアログ

`-Dialog` で表示する。**サクラエディタの Grep ダイアログに合わせたレイアウト**にする。
（この節は Python 版の仕様。PowerShell 版は項目を絞った簡易版のまま）

### レイアウト

```
条件(N)          [コンボ（履歴付き）]                    [検索(F)]
                 □ 単語単位で探す(W)                     [キャンセル(X)]
                 □ 英大文字と小文字を区別する(C)
                 □ 正規表現(E)          <rg と PCRE2 のバージョン>  [ヘルプ(H)]
検索場所(L)      [コンボ（履歴付き）]  [...]
                 □ サブフォルダーも検索(S) [上階層へ(U)] [現フォルダー(G)]
                 □ カレントフォルダーが初期値(D)
                 □ 隠しファイルも検索する
対象ファイル(I)  [コンボ（履歴付き）]
除外ファイル(J)  [コンボ（履歴付き）]
除外フォルダー(K)[コンボ（履歴付き）]
┌結果出力────┐┌結果出力形式──┐┌その他──────────────┐
│○ 該当行(1)  ││○ ノーマル(4) ││□ ファイル毎最初のみ検索(7) │
│○ 該当部分(2)││○ ファイル毎(5)││ 文字コードセット(A) [コンボ] │
│○ 否該当行(3)││○ 結果のみ(6) │└──────────────────┘
└───────────┘└────────────┘
```

`rg` と `PCRE2` のバージョン表示は、サクラエディタの `bregonig.dll Ver...` 表示にあたる。

### rg への変換

| 項目 | 変換 |
|---|---|
| 条件 | パターン |
| 単語単位で探す | §8 の文字種境界（正規表現 ON 時は `-w`） |
| 英大文字と小文字を区別する | ON: `-s` / OFF: `-i` |
| 正規表現 | OFF のとき `-F` |
| 検索場所 | 検索パス |
| サブフォルダーも検索 | OFF のとき `--max-depth=1` |
| 隠しファイルも検索する | `--hidden` |
| 対象ファイル | `;` か `,` で分割して `-g <値>`。**空欄と `*.*` は「すべて」の意味で `-g` を付けない** |
| 除外ファイル | 同じく分割して `-g !<値>` |
| 除外フォルダー | 同じく分割して `-g !<値>/**` |
| 結果出力 = 該当行 | （何も付けない） |
| 結果出力 = 該当部分 | `-o` |
| 結果出力 = 否該当行 | `-v` |
| ファイル毎最初のみ検索 | `-m 1` |
| 文字コードセット | `--encoding`（§9.2） |

`-v` を付けると rg の出力に桁が含まれず `path:line:text` の 3 項目になるので、
その形式も解析できるようにし、桁は 1 とする。

### 9.1 結果出力形式

| 形式 | 出力 | タグジャンプ |
|---|---|---|
| ノーマル | `C:\path\file.c(12,5): 内容` | できる |
| ファイル毎 | ファイル名の行に続けて `\t(12,5): 内容` | **できない** |
| 結果のみ | マッチした行の内容だけ | **できない** |

ノーマル以外は行にファイル名が無いため、タグジャンプの対象にならない。

### 9.2 文字コードセット

rg はサクラエディタのような 1 ファイルごとの文字コード判定ができない。
`--encoding` を指定するとすべてのファイルをその文字コードとして読む。

| 選択肢 | rg への指定 |
|---|---|
| 自動選択 (UTF-8 + Shift_JIS) | 指定なしと `sjis` の **2 回検索**（**既定**） |
| 自動選択 (UTF-8) | 指定なし（rg 既定。UTF-8 と BOM 付きファイルを判定） |
| UTF-8 / Shift_JIS / EUC-JP / UTF-16LE / UTF-16BE | `--encoding utf-8` など |

2 回検索するときは、単純に結果を足すと ASCII の検索語で同じ箇所が両方の回に当たって
重複する。そのため**ファイルごとにどちらの回の結果を採るか**を決める。

- ファイルの先頭 1MB を読み、UTF-8 として復号できる、または UTF-8 / UTF-16 の BOM が
  付いていれば「UTF-8 側」とし、1 回目（指定なし）の結果だけを採用する
- そうでなければ「Shift_JIS 側」とし、2 回目の結果だけを採用する

これにより 1 ファイルにつき必ずどちらか一方だけが残る。
また 2 回検索したときは結果の順序が混ざるので、パス・行・桁で並べ直す。

### 9.3 挙動

- 検索文字列の初期値は `-Word` で外から与える
- **検索場所の初期値は前回検索したフォルダー**（`Folder` に保存されている値）。
  「カレントフォルダーが初期値(D)」が ON のとき、または前回の記録が無いときだけ
  `-Folder` で渡された値（マクロなら編集中ファイルのフォルダー）を使う
- 「現フォルダー(G)」ボタンは前回のフォルダーではなく `-Folder` の値へ飛ぶ
- Enter または `Alt+F` で検索、Esc または `Alt+X` でキャンセル
- チェックボックスとボタンには `Alt` のアクセラレータを割り当てる（W / C / E / S / U / G / N / L / H）
- 上階層へ(U) は検索場所を 1 つ上へ、現フォルダー(G) は起動時のフォルダーへ戻す
- ダイアログを出すモニターは `WindowPos` で決める（`-Pos` で上書き可）
  - `active`（既定）: Tk のウィンドウを作る**前に**控えたフォアグラウンドウィンドウのモニター
  - `cursor`: マウスカーソルのモニター / `primary`: Tk 任せ（プライマリ）
  - `MonitorFromWindow` / `MonitorFromPoint` + `GetMonitorInfo` で作業領域を得て中央に置く
  - フォアグラウンドウィンドウが自分自身のものだった場合は採用せず、カーソル基準に落ちる
  - **マクロは `python.exe` ではなく `pythonw.exe` で起動すること。**
    `python.exe` はコンソールウィンドウを作り、それが一瞬前面に出るため、
    起動元ウィンドウがサクラエディタではなくコンソールになってしまう
  - **geometry を設定したら `update_idletasks()` で反映させること**。
    しないと後続の `focus_force()` で既定位置のままマップされる
- 起動時は条件にフォーカスし、全選択しておく
- 入力欄はすべて同じ幅にそろえる。`...` ボタンは検索場所の右に置く
  （エンジンのバージョン表示を同じ列に置くと列幅が広がって検索場所だけ短くなるので、
  正規表現のチェックと同じ行にまとめる）
- OK 時の入力チェック
  - 条件が空 → メッセージを出して閉じない
  - 検索場所が実在しない → メッセージを出して閉じない
- 確定したら検索場所へカレントディレクトリを移す

### 9.4 サクラエディタにあって実装しない項目

| 項目 | 理由 |
|---|---|
| 編集中のテキストから検索(M) | 外部プロセスなのでエディタのバッファを参照できない |
| フォルダー毎に表示(8) | タグジャンプできない形式が増えるだけなので省略 |
| ベースフォルダー表示(9) | タグジャンプには絶対パスが要るため省略 |
| CP | rg に対応する指定が無い |

## 10. 設定の永続化

ダイアログの入力内容を JSON で保存し、次回起動時に復元する。

- 保存先: `%APPDATA%\rgs\dialog.json`
  （`APPDATA` が無ければ `LOCALAPPDATA` → `TEMP` の順にフォールバック）
- 読み込みは **BOM 付き UTF-8 でも読めるようにする**
  （PowerShell 版が BOM 付きで書くため）。書き込みは BOM 無し UTF-8
- 読み書きに失敗しても既定値で動作を継続する（例外を投げない）

| キー | 内容 |
|---|---|
| `Word` `Folder` `Files` `ExcludeFiles` `ExcludeDirs` | 各入力欄 |
| `Case` `Whole` `Regex` `Sub` `Hidden` `FirstOnly` | 各チェックボックス |
| `Output` | `line` / `part` / `invert` |
| `Format` | `normal` / `perfile` / `only` |
| `Encoding` | 文字コードセットの選択肢のラベル（空なら一覧の先頭＝既定） |
| `WindowPos` | ダイアログを出すモニター `active` / `cursor` / `primary` |
| `CurrentFolderDefault` | 検索場所の初期値に `-Folder` を使うか（既定 false＝前回のフォルダー） |
| `History` | 入力欄ごとの履歴（各 16 件まで） |

既定値はサクラエディタの Grep ダイアログに合わせる。

```
対象ファイル      *.*
除外ファイル      *.msi;*.exe;*.obj;*.pdb;*.ilk;*.res;*.pch;*.iobj;*.ipdb
除外フォルダー    .git;.svn;.vs
文字コードセット  自動選択 (UTF-8 + Shift_JIS)
```

## 11. 実行ファイルの探索

### ripgrep

1. 環境変数 `RG_EXE`
2. PATH 上の `rg`（`rg.exe` だけでなく `rg.cmd` / `rg.bat` も拾う）
3. VS Code 同梱の `rg.exe`
   （`%LOCALAPPDATA%\Programs\Microsoft VS Code\...\@vscode\ripgrep*\bin\...\rg.exe`。
   フォルダ全体の再帰検索は遅いのでワイルドカードで直接叩く）

見つからなければエラーメッセージを出して終了コード 1。

### サクラエディタ

1. 環境変数 `SAKURA_EXE`
2. `%ProgramFiles(x86)%\sakura\sakura.exe`
3. `%ProgramFiles%\sakura\sakura.exe`
4. `%LOCALAPPDATA%\Programs\sakura\sakura.exe`
5. PATH 上の `sakura.exe`

`-Stdout` と `-DryRun` のときは不要なので、見つからなくてもエラーにしない。

### 起動オプション

| 用途 | コマンドライン |
|---|---|
| 結果一覧を開く | `sakura.exe -R -Y=<ヘッダー行数+1> -- <結果ファイル>` |
| 先頭ヒットを開く | `sakura.exe -Y=<行> -X=<桁> -- <ファイル>` |

`-R` はビューモード、`-Y` は行位置、`-X` は桁位置、`--` はオプション終端。

## 12. 終了コード

| 値 | 意味 |
|---|---|
| 0 | 正常（ヒットあり、またはダイアログのキャンセル） |
| 1 | 該当なし、または実行ファイルが見つからない |
| 2 | 引数不正 |
| 3以上 | rg の終了コードをそのまま返す |

## 13. サクラエディタからの呼び出し

### マクロ（WSH）

サクラエディタは拡張子でマクロ種別を判別する（`.js` = JScript、`.vbs` = VBScript）。
Python をマクロとして直接書くには ActiveScript エンジンの登録が必要なので、
**マクロは薄いランチャに留め、本体は外部プロセスとして起動する**。

| マクロ | 起動方法 | 結果の出力先 |
|---|---|---|
| `rgs.vbs` | `WScript.Shell.Run`（非同期） | サクラエディタの新しいタブ |
| `rgs_quick.vbs` | `Editor.ExecCommand`（同期） | アウトプットウィンドウ |

マクロが渡す初期値:

- 検索語: `Editor.ExpandParameter("$C")`（選択範囲、なければカーソル位置の単語）
- フォルダ: `Editor.ExpandParameter("$F")` からファイル名を除いたもの

### ExecCommand の実行制御オプション

| 値 | 意味 |
|---|---|
| `0x001` | 標準出力を得る |
| `0x002` | 標準出力を編集中のウィンドウへ（指定なしならアウトプットウィンドウ） |
| `0x040` | ヘッダー・フッター情報を出力しない |
| `0x080` | **標準出力を UTF-8 で受け取る**（これが無いと日本語が化ける） |
| `0x200` | 第 3 引数のカレントディレクトリを有効にする |

`rgs_quick.vbs` では `0x001 + 0x040 + 0x080 (+ 0x200)` を使う。

## 14. 既知の制限

- `rgs_quick.vbs` は検索語に `"` を含めると引数の引用符が壊れる
- ダイアログの「単語単位」と「正規表現」を同時に ON にすると、
  単語境界はサクラエディタ互換ではなく rg 標準（`-w`）になる
- 矩形選択や複数行の選択範囲は、`$C` の仕様上 1 行目だけが検索語になる
