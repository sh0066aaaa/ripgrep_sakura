# rgs 仕様

ripgrep の検索結果をサクラエディタで開くツールの仕様。
実装言語に依存しない形で書いてある（PowerShell 版 / Python 版はどちらもこの仕様に従う）。

## 1. 目的

ripgrep で検索し、その結果を **サクラエディタの Grep 結果形式** に変換して
サクラエディタ上で開く。結果行にカーソルを置いて `F12`（タグジャンプ）を押すと
該当のファイル・行・桁へ飛べる状態にする。

## 2. 全体の流れ

```
引数解析 → (ダイアログ) → rg 実行 → 出力を整形 → 出力先へ渡す
                                                  ├ 一時ファイル + サクラエディタ起動 (既定)
                                                  ├ 標準出力 (-Stdout)
                                                  └ 先頭ヒットを直接開く (-Direct)
```

## 3. コマンドライン

```
rgs [制御スイッチ...] [rg の引数...]
```

制御スイッチは**必ず先頭**に置く。それ以外の引数はすべて rg にそのまま渡す。

| スイッチ | 動作 |
|---|---|
| （なし） | 結果を一時ファイルに書き、サクラエディタで開く |
| `-Dialog` | 検索ダイアログを表示し、その内容で検索する |
| `-Direct` | 先頭ヒットのファイルを、その行・桁で直接開く |
| `-Stdout` | 結果を UTF-8 で標準出力へ書く（サクラエディタのアウトプットウィンドウ用） |
| `-DryRun` | rg を実行せず、渡す引数とカレントディレクトリを表示して終了 |
| `-WordJp` | サクラエディタ互換の単語単位検索に変換する（§8） |
| `-Word <値>` | ダイアログの検索文字列の初期値 |
| `-Folder <値>` | ダイアログのフォルダの初期値 |

rg には常に `--vimgrep --no-heading --color never` を付ける。

引数が無く `-Dialog` も無い場合は usage を表示して終了コード 2。

## 4. 出力形式

サクラエディタのヘルプ「タグジャンプ」記載の形式に合わせる。

```
□検索条件  <ユーザーが指定した引数>
□フォルダ  <検索したフォルダの絶対パス>
□既定設定  <使用した rgrc のパス>      ← rgrc を使ったときだけ
C:\path\to\file.c(12,5): マッチした行の内容
C:\path\to\file.c(30,1): マッチした行の内容

該当 2 件
```

- ファイルパスは**絶対パス**。区切りは `\`
- 行番号・桁位置は 1 始まり
- ヘッダー行が `□` で始まるのはサクラエディタの Grep 結果に合わせたもの
  （アウトライン解析でも認識される）
- 該当が 0 件のときは `該当なし` の 1 行のみを出力し、終了コード 1

## 5. 桁位置の変換

**rg の `--vimgrep` が返す桁はバイト単位、サクラエディタのタグジャンプは文字単位。**
そのまま渡すと日本語を含む行で桁がずれる。

変換規則:

1. マッチ行のテキストを UTF-8 バイト列にする
2. 先頭から `(rg の桁 - 1)` バイトを取り出す
3. それを UTF-8 として復号し、**UTF-16 コード単位の長さ** を数える
4. その値 + 1 が サクラエディタ の桁

サクラエディタのヘルプに「桁位置は改行単位の行の先頭からの文字数
(サロゲートは1文字で2換算)で先頭を1とします」とあるため、
Python では `len(prefix.encode('utf-16-le')) // 2` で数える。

## 6. 文字コード

| 対象 | 規則 |
|---|---|
| rg の出力 | UTF-8。バイト列のまま受け取り、自前で復号する |
| 結果の一時ファイル | **BOM 付き UTF-8**。サクラエディタの自動判定を確実にするため |
| `-Stdout` の出力 | BOM 無し UTF-8 のバイト列を直接書く（コンソールの既定エンコーディングを経由しない） |
| `.cmd` ファイル | **ASCII のみ**。cmd.exe は cp932 で読むため、日本語コメントを入れると壊れる |
| `.vbs` ファイル | Shift_JIS (cp932) |

## 7. rg の呼び出し

### 7.1 検索パスの補完

rg は**パス未指定かつ標準入力がパイプ**のとき標準入力を検索するため、
サクラエディタの `ExecCommand` から呼ぶと入力待ちで固まる。

引数を走査して位置引数（オプションでもその値でもないもの）を数え、
**1 個以下（＝パターンのみ）なら `./` を末尾に足す**。
値を取るオプション（`-e -g -t -T -m -A -B -C -M -j -f -r -E --glob --iglob --type
--type-not --regexp --replace --file --max-count --max-depth --max-columns
--encoding --pre --sort --sortr --threads --ignore-file --context
--before-context --after-context`）の次の引数は値として読み飛ばす。

**この比較は大文字小文字を区別すること。** 区別しないと `-F`（固定文字列）が
`-f`（`--file`）と誤判定され、検索語が読み飛ばされる。

### 7.2 既定オプション

環境変数 `RIPGREP_CONFIG_PATH` が未設定なら、スクリプトと同じ場所か
リポジトリ直下の `rgrc` を設定する。rg 自身がこのファイルを読む。
コマンドラインで指定した引数のほうが優先される（rg の仕様）。

## 8. 単語単位検索（サクラエディタ互換）

rg の `-w` は Unicode の単語境界を使うため、漢字・かなも単語構成文字になる。
そのため `test` は `test用` にマッチしない。
サクラエディタは**文字種の変わり目**を単語の区切りとみなすのでマッチする。

`-WordJp` とダイアログの「単語単位で探す」は後者に合わせる。

検索語の**先頭と末尾の文字種**を判定し、同じ文字種の文字が隣接することを
禁止する先読み・後読みを組み立てて PCRE2（`-P`）で検索する。

| 文字種 | 文字クラス |
|---|---|
| 英数字・アンダースコア | `0-9A-Za-z_` |
| ひらがな | `\x{3041}-\x{309F}` |
| カタカナ | `\x{30A0}-\x{30FF}\x{FF66}-\x{FF9F}` |
| 漢字 | `\x{3400}-\x{4DBF}\x{4E00}-\x{9FFF}\x{3005}` |

```
test  ->  (?<![0-9A-Za-z_])test(?![0-9A-Za-z_])
用    ->  (?<![\x{3400}-\x{4DBF}\x{4E00}-\x{9FFF}\x{3005}])用(?![...同じ...])
```

検索語は正規表現エスケープしてから挟む。`-F` と `-w` は取り除き、`-P` を足す。

以下の場合は rg 標準の `-w` にフォールバックする。

- 正規表現モードと併用したとき（境界の判定ができないため）
- rg が PCRE2 無しでビルドされているとき（`rg --pcre2-version` の終了コードで判定）

## 9. 検索ダイアログ

`-Dialog` で表示する。サクラエディタの Grep ダイアログ相当。

| 項目 | 種類 | rg への変換 |
|---|---|---|
| 検索文字列 | テキスト | パターン |
| フォルダ | テキスト + 参照ボタン | 検索パス |
| ファイル | テキスト（`*.c;*.h`） | `;` か `,` で分割し、それぞれ `-g <値>` |
| 大文字小文字を区別する | チェック | ON: `-s` / OFF: `-i` |
| 単語単位で探す | チェック | §8 の変換（正規表現 ON 時は `-w`） |
| 正規表現 | チェック | OFF のとき `-F` |
| サブフォルダも検索 | チェック | OFF のとき `--max-depth=1` |
| 隠しファイルも含める | チェック | `--hidden` |

- 検索文字列の初期値は `-Word`、フォルダの初期値は `-Folder` で外から与える
- Enter で検索、Esc でキャンセル
- 起動時は検索文字列にフォーカスし、全選択しておく
- OK 時の入力チェック
  - 検索文字列が空 → メッセージを出して閉じない
  - フォルダが実在しない → メッセージを出して閉じない
- 確定したらフォルダへカレントディレクトリを移す

## 10. 設定の永続化

ダイアログの入力内容を JSON で保存し、次回起動時に復元する。

- 保存先: `%APPDATA%\rgs\dialog.json`
  （`APPDATA` が無ければ `LOCALAPPDATA` → `TEMP` の順にフォールバック）
- 保存するキー: `Word` `Folder` `Files` `Case` `Whole` `Regex` `Sub` `Hidden`
- 読み書きに失敗しても既定値で動作を継続する（例外を投げない）

## 11. 実行ファイルの探索

### ripgrep

1. 環境変数 `RG_EXE`
2. PATH 上の `rg`（`rg.exe` だけでなく `rg.cmd` / `rg.bat` も拾う）
3. VS Code 同梱の `rg.exe`
   （`%LOCALAPPDATA%\Programs\Microsoft VS Code\...\@vscode\ripgrep*\bin\...\rg.exe`。
   フォルダ全体の再帰検索は遅いのでワイルドカードで直接叩く）

見つからなければエラーメッセージを出して終了コード 1。

### サクラエディタ

1. 環境変数 `SAKURA_EXE`
2. `%ProgramFiles(x86)%\sakura\sakura.exe`
3. `%ProgramFiles%\sakura\sakura.exe`
4. `%LOCALAPPDATA%\Programs\sakura\sakura.exe`
5. PATH 上の `sakura.exe`

`-Stdout` と `-DryRun` のときは不要なので、見つからなくてもエラーにしない。

### 起動オプション

| 用途 | コマンドライン |
|---|---|
| 結果一覧を開く | `sakura.exe -R -Y=<ヘッダー行数+1> -- <結果ファイル>` |
| 先頭ヒットを開く | `sakura.exe -Y=<行> -X=<桁> -- <ファイル>` |

`-R` はビューモード、`-Y` は行位置、`-X` は桁位置、`--` はオプション終端。

## 12. 終了コード

| 値 | 意味 |
|---|---|
| 0 | 正常（ヒットあり、またはダイアログのキャンセル） |
| 1 | 該当なし、または実行ファイルが見つからない |
| 2 | 引数不正 |
| 3以上 | rg の終了コードをそのまま返す |

## 13. サクラエディタからの呼び出し

### マクロ（WSH）

サクラエディタは拡張子でマクロ種別を判別する（`.js` = JScript、`.vbs` = VBScript）。
Python をマクロとして直接書くには ActiveScript エンジンの登録が必要なので、
**マクロは薄いランチャに留め、本体は外部プロセスとして起動する**。

| マクロ | 起動方法 | 結果の出力先 |
|---|---|---|
| `rgs.vbs` | `WScript.Shell.Run`（非同期） | サクラエディタの新しいタブ |
| `rgs_quick.vbs` | `Editor.ExecCommand`（同期） | アウトプットウィンドウ |

マクロが渡す初期値:

- 検索語: `Editor.ExpandParameter("$C")`（選択範囲、なければカーソル位置の単語）
- フォルダ: `Editor.ExpandParameter("$F")` からファイル名を除いたもの

### ExecCommand の実行制御オプション

| 値 | 意味 |
|---|---|
| `0x001` | 標準出力を得る |
| `0x002` | 標準出力を編集中のウィンドウへ（指定なしならアウトプットウィンドウ） |
| `0x040` | ヘッダー・フッター情報を出力しない |
| `0x080` | **標準出力を UTF-8 で受け取る**（これが無いと日本語が化ける） |
| `0x200` | 第 3 引数のカレントディレクトリを有効にする |

`rgs_quick.vbs` では `0x001 + 0x040 + 0x080 (+ 0x200)` を使う。

## 14. 既知の制限

- `rgs_quick.vbs` は検索語に `"` を含めると引数の引用符が壊れる
- ダイアログの「単語単位」と「正規表現」を同時に ON にすると、
  単語境界はサクラエディタ互換ではなく rg 標準（`-w`）になる
- 矩形選択や複数行の選択範囲は、`$C` の仕様上 1 行目だけが検索語になる
